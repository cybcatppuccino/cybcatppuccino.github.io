几何工作台

✦Pretty · 画面美化

优先使输入条件在几何精度内成立，再保持条件调整布局。滑块可回放真实求解路径。

条件语法 · 7 条规则先按 Enter 或「确认」解析；单条输入一项条件，支持连续等号。
① 对象、括号与命名

点用画板名称 A B C；直线用已有对象 l 或 (A B)、(A,B)；圆用已有 c 或 (A B C)、c(A,B,C)。标量式里的 (A B) 表示线段长度。点必须存在且类型正确；相邻单字母点可写 ABC（只在无同名对象时拆开）。

② 点的位置与基本构造

col A B C D E / collinear(A,B,C)：至少 3 点共线；cyc A B C D E / cyclic(A B C D)：至少 4 点共圆。A in c、subset(A,l)、sub A c(B C D)、onl A l、onc A c：点在线/圆上。midp M A B：M 为 AB 中点。

③ 直线与圆之间的关系

perp A B C D、perp(l,(A,B))：线线垂直；para l (A B)：线线平行；tan c l / tangent(c1,c2)：相切。para c l 或 para c1 c2 也按相切解释；perp l c 表示直线经过圆心，perp c1 c2 表示两圆正交。线线不能用 tan。

④ 距离、面积、比例与数式

dist A B = d(C D) = 2 E F = sqrt5*G H；A B / D E = C F / I J；(A B)^2 + (B C)^2 = (A C)^2；S(A,B,C) = area D E F。支持 distance、len、sqrt(5)、sqrt5、pi、加减乘除、乘方、括号、省略乘号和链式等号。长度、面积、角度不能错误混加；裸数字允许表示相应几何量的值。

⑤ 角度、角度运算与单位

ang(A,B,C) 是以 B 为顶点、范围 0–180° 的无向角；angle(A,B,C,D) 为 AB 到 CD 的有向角。例：ang(A B C)+angle(D,E,F,G)=90、ang A B C D = 2*ang R S T U、perp A B C D、ang A B C D = pi/2。明确单位推荐 90° / 90deg（度）和 pi/2（弧度）；为兼容旧语法，裸常数绝对值大于 2π 时按度，否则按弧度。角差按整周取模。

⑥ 三角形全等与相似

cong (A B C) (D,E,F)、cong A B C D E F：对应顶点按 ABC ↔ DEF 的顺序全等；simtri(A,B,C)(D,E,F)、sim A B C D E F：按顺序相似。另 cong A B C D 是 AG 风格的 AB=CD。

⑦ AG2 谓词与精度边界

eqangle A B C D E F G H、eqratio A B C D E F G H、aconst A B C D 90、rconst A B C D 1/2。已有别名：coll、cyclic、perpendicular、parallel、tangent、subset、similar。Pretty 优先满足条件；理想场景可达到近机器精度，但不能保证任何非凸系统均有解或总达到 10⁻¹⁵。只有当前满足且可无损翻译的条件才作为 AG2 的用户附加假设；关系检索的「微扰复验」默认关闭。

注意：Pretty 只在点击「计算 Pretty」后改变画板，内部多起点探索仅在副本中进行；路径中间帧不保证满足最终条件。
