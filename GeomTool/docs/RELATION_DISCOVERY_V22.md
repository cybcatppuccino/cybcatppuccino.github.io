# v2.2 · 关系发掘架构与判定约定

这是**基于当前数值坐标**的候选关系扫描器，不是符号证明器；用户移动自由点后，扫描快照失效，需要重新扫描。它不会向 Kernel 写入辅助点、线、圆，也不会替换现有题库或 Pretty。

## 文件边界

- `assets/relations/core.js`：取快照、过滤有效对象、生成一切非退化点对隐含直线和点对距离；按需预计算点到直线距离候选，提供统一长度、方向、角度和比例容差、二分索引、标记描述符。依赖：无。
- `assets/relations/detectors.js`：独立规则注册表（41 种关系）；用户选择的规则共用同一只读几何缓存。长度关系采用排序数组 + 二分窗口找倍数；相似与全等三角形也采用排序与单轴扫描；平行与垂直共用相同的线候选，不限定是物理存在的直线。所有规则输出相同的 `id/kind/title/detail/marks/score` 格式。
- `assets/relations/overlay.js`：按稳定的 Kernel 对象 ID 查询最新几何，解析点、显式线、点对隐含线、显式圆、以 A 为圆心过 B 的隐含圆、外接圆、垂距标注、实角弧、切点。辅助段使用独立虚线，并且显示即席的 AB 或 CD，即使源图只有孤立点。
- `assets/app.js` 与 `index.html`：勾选类别、精度、可见性、扫描、关键词过滤、趣味评分排序、80 条分页渲染及点击结果查看。**分页不影响扫描/保存的全部候选数**。

## 空间语义

默认从 `Kernel.snapshot()` 里仅取有效且当前可见的 `point/line/circle`。点形成的隐含直线总是使用两个**当前可见的**点；隐藏对象（包括默认隐藏的六个复坐标参考对象）不会偷渡进普通扫描。开启“搜索隐藏对象”后包含所有有效隐藏对象，包含系统参考。`axes` 或复坐标显示打开后，系统参考自动进入普通扫描。

- “AB”指两点间的距离时用线段 AB；用于平行、垂直和点到 BC 的距离时则使用无限延伸的支撑直线 AB。
- 显式线对象保留其本来存在的 ID；点对隐含线拥有 `P:A|B` 的临时描述，不写入依赖图。几何位置相同但语义引用不同的显式线与隐含线仍可独立检索。与自身/与同一条重合直线的“平行”不会报为新结论。
- 圆 `⊙(A,B)` 指**以 A 为圆心经过 B 的圆**，搜索线圆切线和圆圆切线时按需求生成；这不是 A、B 两点唯一确定的无中心圆。
- 所有角弧都用实际的 `A–V–B` 点射线计算，不使用无限直线的任意正/反方向；圆切点/垂足则从关系中保存的对象引用重新计算。角和距离的辅助段不要求画板上已存在对应线段。
- “常见倍数”包含 1、2、3、4、3/2、4/3、√2、√3、黄金比例 φ。扫描比较线段长度、点到显式线、点到任意两点所定直线的距离。

## 分类

41 个选择项，分为：基础位置、线与角、长度与面积、圆与切线、三角形、四边形、变换。子类例如三角形特殊点同时识别重心、外心、垂心、内心、三旁心、九点圆心；三角形特殊线同时识别中线、高线、角平分线和显式中垂线。一条特殊线可能同时具有多个特征，分别保留。

默认不勾选“重合点”（因其通常是重复对象），其它类别默认勾选。面板既能全选/清空，也可展开分类逐一勾选；点击扫描后按用户指定的精度判定。用户可搜索结果标题、类型和数学表达式，优先看到几何趣味评分高的关系。每条关系仅保留数值快照推断，严禁把它标记为形式证明。

## 性能与边界

候选关系**不设置固定结果数/类别数上限**。输出只依赖真正发现的关系数量；界面一次只构建 80 项 DOM，点“显示更多”继续逐页加载。对 O(N²) 点对候选、三角形、隐含圆使用按所需规则初始化；带顺序性/比例性的比较采用排序索引，避免所有距离值的双重暴力枚举。但是从组合枚举本身生成大量真关系（规则格点、共圆多边形等）仍然需要时间与内存；非常大的图可能短暂阻塞主线程。

对用户拖拽点或 Kernel 修改，原扫描会标记过期并清除高亮。精度档“严格/标准/宽松”同时规定世界坐标长度（相对于可见图幅）、方向正交性、角度和长度比的误差阈值。复杂病态（近重合点、近共线的外接圆、极大/极小坐标、浮点舍入）仍应当由用户核对。
