# GeomTool v4.1 — 关系探索重构与 50 张傻瓜图审计

日期：2026-10-15。基线：用户提供的 GeomTool v4；直接保留其内核、智能选点、多边形实体边、预览和 v3.5 全功能控制台。

## 核心行为与规格

### 1. 一次量和圆半径

- 将**每一个有效的显式圆**的半径 `r(c)` 作为独立一次量，加入原有长度、点到直线距离、一次连等与常用倍数比较。不因同心同半径而删除其中某个圆的身份；退化半径、零线段不可做有意义的非零比值。
- 以构造依赖而非单纯数值相等判断来源：`circle c O A` 和 `onCircle B c` 定义的 `r(c)=OA=OB` 为作图条件；`circleBySegment`、`midpoint`、`circumcenter`、已知交点等也建立可核查的等长原因。偶然同长的自由线段不会被假称为构造结论。
- 部分直接构造操作数 + 部分独立等式组成同一连等时标为“含已知条件”，不能把整个发现当作纯作图定义。

### 2. 平行、等面积、调和点列、去除梯形

- 移除普通梯形和等腰梯形的**检测类别及 UI 入口**，不再因为许多平行线枚举出大量梯形。平行四边形、矩形、菱形、正方形、筝形仍在。
- 同底三角形的第三顶点连线平行于底边时，标记等面积作为平行条件的蕴含；正反位置和不同底边的情况不作不当推断。纯蕴含的评分不超过 25。
- 调和点列四点排列不再依赖字母先后；保存所检测的准确交叉配对，以及对应的 `AC·BD=AD·BC` 乘积等式。若二次量扫描重复报出同一条两项等式，则合并到调和关系并仍可检索；含有额外独立操作数的连等不随意删除。

### 3. 二次量（默认关闭）

一律采用长度平方量纲，作为可选单独类别 `quadraticRatio`：

- 线段平方 `AB²`、**圆半径平方** `r(c)²`、两条线段长度乘积 `AB×CD`；
- 两种平方二项式 `AB² + CD²` 和 `AB² − CD²`，支持勾股型 / 平方差型关系；
- 三角形面积 `[ABC]`、圆面积 `S(c)`、带**正负号**的点幂 `Pow(P,c)`、带符号的向量点积 `⟨PA,PB⟩`；
- 同值合并成连等簇；寻找倍率 `2、3、4、3/2、4/3、√2、√3、φ` 及负倍率，支持逆倍率搜索；避免退化为零的数值除法。

为抑制虚假强关系，记录操作数的代数规范型：`AB=AC` 自动得到的 `AB×EF=AC×EF` 不独立算新发现；乘积比例若有公共乘因子会约简；圆点幂定义 `CP²−r(c)²=Pow(P,c)` 不会因新增自由点而刷出发现；绝对数值恒等式不冒充构造约束。

**性能上限（须明确）**：普通一次量及原始平方依旧全量枚举；二次量中**乘积**默认只使用最多 **66** 条候选线段，平方和差默认只取最多 **20** 个平方原子。超过会在扫描统计中告知截断数量。可在控制台更改：

```text
relations kinds quadraticRatio on
relations quadratic
relations quadratic product 90
relations quadratic expression 35
relations scan
```

亦可开发调用 `GeomRelationEngine.scan(snapshot, {kinds:['quadraticRatio'], quadraticProductLimit:90, quadraticExpressionLimit:35})`。提高上限可能使交互明显变慢，请按图规模选择。枚举上限不是完整符号代数穷举，`r(c)` 按量纲进入平方表，但乘积列表目前为“线段×线段”，不枚举任意半径与线段乘积的全部组合。

### 4. 四边形蕴含图及检索

蕴含事实绑定到**实际对象 ID、四个顶点和线段操作数**，没有只凭“正方形”标签给别的四边形加结论。

| 对象 | 子关系（按真实点序展开） |
| --- | --- |
| 一般平行四边形 | 两组对边平行、两组对边等长、对角线互相平分、两组三角形全等、两组等面积、两组对角相等、四组邻角互补 |
| 矩形 | 继承平行四边形；四个直角、对角线等长、四顶点共圆 |
| 菱形 | 继承平行四边形；四边等长、两条对角线垂直、四个顶角的对角线角平分 |
| 正方形 | 矩形 + 菱形的结论，仍可通过“矩形”“菱形”搜索找到 |
| 筝形 | 两组相邻边等长；**对应的正确对称轴**垂直并平分另一对角线；两个三角形全等、等面积、非轴上对角相等、对称轴平分两端顶角（两种顶点次序分别检查） |

可在搜索结果中查询已被强图形吸收的某条具体边长关系（例如 `AB=CD`）。推导记录进入 `implicationGraph` 的 `F:v41:*` 事实节点，并保留指向主关系的可追溯边。一般筝形不误报为共圆或平行四边形。

### 5. 来源、等价和评分

- 纯构造定义：最高 **22 分**；三条同锚点的天然共点：最高 **12 分**；
- 纯逻辑蕴含 / 恒等变形：最高 **25 分**；
- 同一连等混合已知和待发现关系：最高 **42 分**；
- 非平凡关系仍由原评分器衡量，例如真实高线汇交不因三线共享后算出的垂心点而归为三线同端点的构造定义。

判定遵循**候选级**而不只是关系类别级：“矩形有等长边”不能据此删除全部与矩形同名的独立长度连等；只有具体点边全部属于同一蕴含闭包时才合并。

### 6. UI 标签

对象列表、详情标题、画布点标签及复数公式对象头使用其 **ID**，不产生 `P1/P1`、`c/c` 等双重命名；旧版导入时由 v4 已有的迁移逻辑处理名称。

**已知历史差异**：旧 `tests/kernel.test.cjs` 仍断言“自动重名必须报错”，与 v4 规定的自动递补相反；`tests/v2.test.cjs` 仍依赖 v4 以前的系统 ID；`tests/v33_relations.test.cjs` 使用不再匹配的对应字段名称。这些断言在原始 v4 就不通过，没有删除或改写来冒充全绿。

**真实性边界**：50 张图是人为设计的**定向回归集，不可能数学上保证发现所有关系或证明所有蕴含**。当前候选大体由数值严格阈值确认，依赖来源识别不是通用符号定理证明。二次量表达式只支持上面的受限类型和倍率，尚不接受任意层级的带括号线性组合或自动推导任意实数系数；高维、多圆复杂配置和大图仍可能有未覆盖关系。若有重要新反例，应添加对应最小构造和“应报 / 不应报 / 应降权”的断言，再扩展规则，而不是把所有数值巧合宣称为定理。
