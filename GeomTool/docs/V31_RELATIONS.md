# GeomTool v3.1：严格数值、几何等价归并和最简关系展示

本版延续 v3 的几何 Kernel、作图工具、Pretty 与离线题库，集中改造关系发掘。入口在 `assets/relations/detectors.js` 的 `scan(snapshot, options)`；依赖于 `groups.js`（几何实体归并）、`core.js`（规范化上下文）、`semantic.js`（逻辑蕴含去重）、`search.js`（同义与逆比查询）、`overlay.js`（视觉证据）。离线启动由 `index.html` 按此依赖顺序加载。

## 1. 先归并、再搜索、最后去重

- **同位置点簇**：严格容差内的 complete-link 聚类，禁止只凭 A≈B、B≈C 就把不接近的 A/C 传递合并；保留原始点名称供关系检索。
- **同一支撑直线**：既有线段、射线、直线及任意不同点的隐含 AB，按照方向、偏移归并。无界支撑线可参与平行、垂直、夹角、交会搜索；有限载体原始范围仍可用于点在线上判断。共线报告最大点集，而非各三点组合。
- **平行/垂直方向簇**：多条平行线合并为一组；两组互相垂直的支撑线只输出一组关系，不输出其笛卡尔积的全部配对。任何已归并线的别名仍可搜索。
- **同圆与共圆**：同心同半径的显式圆合并；共圆规则还枚举非退化的三点圆并按最大共圆点集合并。圆心 A、过 B/C 等半径的虚构圆在切线类检测中归并为同圆。原始圆对象名与辅助描述留作别名。
- **全等 / 相似三角形簇**：三边的排序长度（全等）及归一化长度（相似）以 complete-link 分组，三个及以上同类三角形只报告一次。全等全部成立的簇不再另报相似；如果相似簇里存在非全等三角形，仍显示必要的相似信息。
- **长度与面积簇**：长度对象包括 AB 距离与点到显式/隐含直线的垂距。先分严格等长簇，按簇输出连等；常见倍数再按组输出连比，不枚举 n×m 个同义行。等面积三角形也以连等组表示，面积倍数按等面积簇表示。

扫描过程只建立临时语义索引，不改变原有图形节点、依赖关系、显示状态、导出文件或者手性约定。

## 2. 始终严格 + 正反微扰复验

- 无宽松开关，JS API 传入 `tolerance: 'loose'` 也不改变严格参数：**距离相对阈值 1e-9、方向 1e-9、比例 1e-9、角度 0.000001°**。
- 距离绝对阈值是 `1e-9 × min(sceneSpan, max(1, localScale))`；`localScale` 来源于点的非零最近邻距离中位数；无相邻点时参考已显示圆半径，最后才回退到场景跨度。这样单个遥远点不应放松局部图形的判断阈值。
- 第一遍生成数值候选。第二、第三遍分别对**扫描原始几何快照**的点、线、圆施加方向相反、按 ID 可重现的极小扰动（每个坐标的扰动量不超过当前距离阈值的 1.2%），只重扫第一遍产生过结果的检测类别。
- 仅保留三遍都具有相同**几何语义 ID**的关系；接着再进行逻辑蕴含去重。`unstableRejected` 和 `semanticRemoved` 可在界面查看。

**限度**：这是一项严格的数值稳定性验证，并不是证明关系能在自由点的任意真实扰动下保持。真正恒等的代数构造可能因为独立噪声或病态几何被剔除；反过来，微扰幅度极小也不足以对任何几何偶然巧合给出形式证明。若希望严格证明，还需要对 Kernel 的构造依赖做符号推理。非常大/小的坐标数量级混合时，双精度浮点也有固有局限。

## 3. 去冗余原则：删除蕴含项，而不是盲目删数学能力

| 语义情形 | 保留的代表事实 | 搜索行为 |
| --- | --- | --- |
| 等向量 / 平行四边形 | 平行四边形 | 可查“平行四边形”；等向量不独立计数 |
| 四边形同时是正方形、矩形、菱形、平行四边形 | 正方形（最具体） | 搜索“矩形”“菱形”“平行四边形”均命中正方形 |
| 任意一组 AB ⟂ CD 和特殊 90° / 直角三角形 | 支撑线垂直 | “直角三角形”可命中符合端点构型的垂直关系 |
| 等腰三角形与对应两边相等 | 长度连等 | 可按“等腰”检索有非退化公共顶点的等长边 |
| 对角线垂直 | 一般垂直（包括隐含 AC、BD） | 不重复输出 |
| “AB=CD” 与其他点对等距 | 长度连等（倍率 1） | 每个长度别名可检索 |
| AB:CD=2、DC:BA=1/2 | 同一标准方向的长度连比 | 输入任意逆比、倒序端点均命中同一条 |
| d(A,l)=AB，其中 B 在 l 且 AB ⟂ l | 垂直基本关系 | 不把 AB 重新表达为垂距当作第二个独立等长证据 |
| A、B 到 l 同侧等距，且 AB∥l | 平行支撑线簇（同时启用平行搜索时） | 仅启用距离搜索时仍能查询等距，不因未启用别的类别而丢失事实 |
| 点在既有无限直线上，且已属于同线最大点簇 | 最大共线点集 | 有限线段/射线额外的范围信息仍可单独展示 |
| 现有圆上的点，且已属于该圆的最大共圆簇 | 最大共圆点集 | 圆对象原名仍在别名里 |
| 垂足被明确的垂直支撑线关系覆盖 | 一般垂直 | 只选垂足时仍可显示该关系 |
| 特殊线已经给出同一三角形角平分线 | 三角形特殊线角色 | 其他角平分关系不能因为启用了特殊线类别就被无条件抑制 |
| 多条等面积三角形互比 | 等面积连等或面积连比 | 仍可用其中的三角形标签查找 |

以上采取**局部可验证的蕴含消除**，而非宣称任意几何关系都已经用完备定理系统约简。某些复合关系（例如正方形及其边的其他独立度量）可能仍同时出现，因为它们在不同对象范围下承载额外信息。三角形等边类仍保留为高级几何形状标签。

## 4. 补充非平凡交会关系

- 三条及更多相异**支撑线**在同一点交会：即使交点尚未创建也能报告。自动从公共端点画出的任意线扇不应被当作发现的新共点条件。
- 一点在两圆的**根轴**上但不是两圆交点：通过两圆点幂差判定，同时动态绘制两圆真正的根轴。
- 两支撑线的交点落在显式圆上；两圆的公共点在某线 / 两个公共点构成共弦；三圆及更多显式圆共点。可绘制临时交点而不必事先生成点对象。
- 共点/共圆等多对象条件优先最大集合显示。切触、近同心、几乎平行和外接圆病态构形采用退化检查与微扰复验剔除不稳定报告。

## 5. 检索与可视化

- 当前注册表共 **50 个可勾选检测类别**（v3 的 53 类中删除六种重叠类别，另增三种独立交会类别）。类别数不是完整理论独立公理数，只表示独立的扫描器分支。
- 搜索支持空格、中英文逗号、多关键词 AND、对象名与所有等价别名。支持类型蕴含查询，例如“正方形”按“菱形”检索；支持 `AB:CD=2`、`DC:BA=1/2` 等有向或反向比例表达式。
- 页面默认仍只扫描可见且有效的点/线/圆；“搜索隐藏对象”勾选后搜索全部有效对象。参考系开关显示出的轴、原点与单位圆照常作为对象参与扫描。
- 结果按评分排序；全部稳定候选保留在数据中，界面每批最多渲染 80 行。高亮层补绘原本没有画出的隐含线、长度、切圆、角弧、根轴、临时交点，绝不强迫用户先创建辅助对象。

## 6. 检查与性能

运行 `node tests/v31.test.cjs`、`node tests/v31_semantics.test.cjs` 并继续运行 v3/v2.2 与旧 Kernel/Pretty 回归。v3.1 扩展测试含远离主体构图的离群点、严格误差拒绝、正反比检索、隐藏的假并发、非平凡根轴、双圆公弦、三圆共点、三组相似三角形。实际将你提供题库中的 **Conway_circle** 和 **Malfatti_s_problem** 的转换后构造图送入扫描器做了抽样检查。另做少量 Chromium 操作烟雾测试（关系勾选、逆比搜索、AND 搜索、点击画布高亮）。

没有穷尽 1,447 题或实施随机大规模性能证明。大规模点集可能产生 O(P²) 隐含直线、O(P³) 三角形、O(P⁴) 四边形或较多交会，三遍严格扫描可能需要明显 CPU/内存；**不人为截断结果数**。需要时建议通过勾选具体规则降低计算量。
