# GeomTool v4：命名、智能构造与关系审计

基于 v3.5 增量实现。入口仍是 `index.html`，所有依赖本地化，无网络请求。

## 1. 单一对象名称、自动补位、旧文件迁移

- `id` 就是用户看到的唯一 `label`；所有构造依赖也直接引用这个名字。重命名是整个依赖图的原子操作，可撤销。旧 v3.5 文件在导入/恢复时将原先的 label 映射为真实 ID（如遇重复或非法旧标签则分配新的安全名称）。
- 点按 `A…Z` 最小未使用字母分配，全部占用后按 `P1、P2、…` 找最小未使用序号；指定的自动构造名冲突时同样补位，继续创建，而不是丢弃点击。直线用 `l1、l2、…`，圆用 `c1、c2、…`，多边形用 `poly1、poly2、…`。
- `p_0、p_1、p_i、l_Re、l_Im` 是五个保留的系统点/轴名称；单位圆另保留 `c_unit`。普通对象不能抢占这些名称。它们在对象列表、控制台、导出文件、依赖里均使用同名。
- 自动多边形边命名 `sAB`、`sP1H` 等。被占用时退化为最小可用 `s1、s2、…`。手工重命名的边不再参与边名自动更新。
- 旧 `.geom.json` 导入会保持各对象的构造、数值参数、隐藏状态、依赖关系，同时迁移系统 ID 和独立展示标签；导入后的新导出文件使用统一名称。

## 2. 多边形与几何可组合性

- 多边形最少三个不同顶点；点击第一个顶点立即闭合，还保留双击、Enter 结束。
- 每次创建多边形会附带创建每条 `segment` 内核节点；它们是合法 `line` 载体、拥有自己的独立隐藏/显示、属性、依赖、构造与命名，可供约束点、智能点、交点、垂线、平行线等功能使用。
- 多边形和其自动边线段合为同一个撤销事务；删除多边形会删除自动边及其依赖物，不删除原始顶点。重命名顶点时，依赖、以及仍为自动命名的多边形边，会同步更新。
- v3.5 的旧多边形在导入时自动补建原本没有保存为几何内核节点的边。

## 3. 工具预览和智能选点

- 凡是工具下一步需要点，优先命中已有点，其次识别真实载体交点，再将位置约束在线/圆上，最后才创建自由点。多边形自动边同时进入候选载体集合。
- 工具鼠标移动时调用同一个核心 `previewConstruction` 计算器，**不写入数据图**；下一个输入位置若足以完成构造，就画该预期对象的青色虚线。包含三点圆、圆、定半径圆、直线、线段、射线、中点、中垂线、垂线、平行线、角平分线、切线、特殊心、平移、旋转、位似、对称等现有图形工具。
- 对第三个点之前还未能确定完整几何体的多点操作，用开放点链提示当前选择；多边形已具备三个有效顶点时，鼠标当前候选点加入闭合区域预览。
- 智能交点工具在鼠标悬停交会处显示预期交点；已经创建的点优先复用，避免额外堆叠重合点。
- 输入角度、倍数、半径变化时会重新计算预览；旋转仍同时支持角度与弧度制和 `π` 插入按钮。

## 4. 作图关系的来源与新颖性评分

- 在原 v3.4 的 `GeomConstructionLogic.makeFacts` 基础上，把“两点定线的两个端点在线上”分别登记为两条直接构造事实；已含中点两段相等、中点共线、特殊心、切线及其他定义。
- 关系扫描不再把“画 AB、AC、AD 所以它们在 A 共点”误认为高分性质。关联关系的 **构造锚点** 必须由明确的内核构造输入支持，不能仅凭一对虚拟/隐式点组成的支持线推断；三条不同顶点发出的高线在一个新点相遇仍被识别为真正发现。
- 关系分类为 `construction`（所有该候选关系的事实都由直接作图给定）、`mixed`（分组中含已知条件和新增比较）或 `discovery`。扫描界面显示“作图条件”或“含已知条件”提示。
- 评分上限：纯作图条件最高 22，直接构造锚点共点最高 12，混合条件最多 42。真正发现保持原有深度、稀疏性、关系罕见性评分机制。
- 数值扫描是对已构造对象的候选关系验证，不是形式证明；来源标签来自具体的构造命令和匹配的几何操作数，而不是凭关系类型泛化。对数值偶然重合仍需微扰选项和人工核查。

## 测试

- `node tests/v4_kernel_relations.test.cjs`：重名补位、统一命名、保留名迁移、多边形真实边、线圆交点、删除/撤销、内核计算预览、作图关系。
- `python tests/v4_browser_smoke.py`：Chromium/Playwright 浏览器交互，包含点击首顶点闭合、三点圆动态预览、已有点智能复用、边线段属性、重命名和控制台帮助。
- `node tests/v4_dummy_audit.cjs`：15 个平移及缩放的傻瓜图，结果储存在 `docs/V4_DUMMY_SCENE_AUDIT.json`；区分基础三线共点、中点等长和真正垂心共点。
- v3.4 构造最小图测试涵盖 66 种独立小场景，检查 43 类操作、所有派生构造事实的几何一致性。

**已知历史测试差异：** `tests/kernel.test.cjs` 中断言“同名构造必须抛错”与 v4 新规格（重名自动补位）不再一致。`tests/v2.test.cjs` 期待旧参考 ID `GTREF_*`，而本版本按要求变为 `p_0` 等保留名称。`tests/v33_relations.test.cjs` 的历史对应关系元数据断言在 v3.4/v3.5 原始版也有失败，新版本未声明其已修复。为确保可追溯，旧测试仍按原样保留，没有修改其断言来掩盖差异。
