# GeomTool v3.3 — 关系判定机制设计与边界

该版本直接基于 v3.2；除所需的 **「开启微扰复验」勾选框**、相应简短提示和版本标识外，画板、作图操作、左右面板、几何 Kernel 均保持原有行为。

## 1. 可选微扰与原始坐标

- 勾选框默认为**关闭**：使用当前画板给出的精确数值快照，只执行一次扫描；**判定精度仍然严格**。
- 开启：先用原始快照扫描，再分别扫描两个确定性的、正负方向独立微扰的**内部拷贝**，仅保留在三次扫描中拥有相同语义 ID 的候选。
- 微扰量约为局部点容差的 1.2%；这是数值稳定性过滤，而**不是**允许把构造点移动后的结论当作符号证明。原始 `snapshot` / Kernel / 画布坐标不被写入。
- 程序 API：`GeomRelationEngine.scan(snapshot,{kinds:[...],perturb:false|true})`；返回 `perturbations:0|2`。
- 现有 v3.1/v3.2 历史测试明确打开微扰，以保持当年的测试语义；v3.3 新测试覆盖默认关闭与开启两种情况。

## 2. 分维度数值判定

不同物理量 **不能共享一个带长度单位的绝对误差**。

| 类别 | 主要判定 | v3.3 默认值 | 依据与注意点 |
|---|---|---|---|
| 点位置/线距 | 局部尺度 × 相对误差，另加浮点 ULP 下限 | `1e-9`（位置相对系数） | 最近邻间距的稳健 75% 分位数；远离主体的单个离群点不会成比例放宽局部判断，重合点的微小虚拟分离也不会使估计尺度崩溃 |
| 线方向 | 归一化方向叉积/点积 | `8e-10` | 无量纲；仅对非退化载体参与判断；求交近似平行的阈值相同 |
| 角 | `atan2(abs(cross),dot)`，比较角度差 | `5e-8°` | 尤其改善接近 0°/180° 时 `acos` 丢失精度的问题 |
| 一次量比 | 归一化比例误差 + 位置容差 | `1e-9` | 用于长度、距离倍数，与角度误差分离 |
| 二次量 | 与操作数局部二次尺度相关的误差 | `5e-11`（相对系数） | 面积、长度平方、向量点积、有符号点幂均不再使用长度绝对误差 |

数值阈值是有限精度浮点几何的工程选择，并非精确代数判定。局部估计仍可能在严重退化、高度集中或巨幅平移至浮点极限的图形中失效。严格并不代表形式证明。

## 3. 相似/全等三角形顶点对应

原 v3.2 用排序的三边长度比较，**这个判定可以识别 SSS，但不能确定名称里的顶点对应**。v3.3 对通过 SSS 的每个三角形枚举 6 种顶点排列，验证三条对应边及统一相似倍数，输出正确的三角形排列。

例：`AB=3, AC=4`、`DE=4, DF=3` 时，输出 **△ABC ≅ △DFE**，不会错误地写作 △ABC ≅ △DEF。每条结果的 `correspondences` 保存规范三角形 ID、原始顶点 ID、比例及映射有效性；等腰/等边导致合法映射不唯一时使用确定性的对象 ID 排序。

## 4. 二次量统一系统（按需勾选）

新增 **「二次量连等 / 连比」** 关系检测器，默认未选中（可能在大图上比较昂贵，可手动选中）。它与原有长度、面积检测模块共存，并通过语义层进行蕴含去重。

- 距离的平方 `AB²`（无向）；
- 三角形面积 `[ABC]`（非负）；
- 显式圆的圆盘面积 `S(c)=πr²`；
- **有符号**点幂 `Pow(P,c)=|P-O|²−r²`，圆内为负、圆外为正、接近零时不进行比例除法；
- 三点共享顶点的向量点积 `BA·BC`（有符号）。

这些量的数值量纲统一为长度平方。先按近似同值建立**完全连接**的连等簇，再按 1、2、3、4、3/2、4/3、√2、√3、φ 搜索簇级比值，支持有符号倍率及倒数查询。`metric.high/low` 保留名称与操作数别名，搜索 `AB²:CD²=2`、`CD²:AB²=1/2` 指向同一个结果。

对 dot/area 一类十分容易发生的**恒等重述**，还通过反事实改变共同自由顶点来剔除例如“完全自由 F 时，`AB·AF` 与 `[ACF]` 的恒定倍比”。平方长度与单独长度比例、纯面积比等只有在被现有可见强证据**完整覆盖**时才会合并，不会因为共享几个对象就删除混合类别中真正不同的关系。

## 5. 可追踪的构造事实与蕴含图

`assets/relations/provenance.js` 为关系提供两个语义维度：

1. **作图来源**：`origin:'construction'|'discovered'`；`constructionWitnesses` 含产生直接事实的构造节点 ID/标签/操作/理由。例如 `M=midpoint(A,B)` 的扫描结果会把 `MA=MB`、中点和共线相关事实标注为中点构造自带事实；即便图中恰好存在其他等长对象，也只表示组内包含此证据，不会误称整条连等都来自中点工具。
2. **逻辑蕴含**：`IMPLICATIONS` 表保存特殊四边形、全等→相似/等面积、垂心组、角平分线、中点等**类型之间的单向蕴含**。`impliedKinds` 支持在没有显式扫描弱类别时仍可按其名称检索。数值消冗的 `consolidate` 对需要删除的弱事实检查**相同操作数/相同圆/相同支撑线及所有成员是否覆盖**，避免“只凭类别名称”误删真正独立关系。已有 `semantic.js` 对全等/等面积、正方形/共圆、特殊心/垂心组等提供证据级规则。

目前不是完整自动数学证明器：蕴含图以可验证局部规则为主，深层几何定理仍可能没有被消冗，不能把输出的 `impliedKinds` 误读为对任何其他对象都成立。

## 6. 有趣程度

分数改由两个主要部分构成，合计最多 100：

- **独立信息量**：关系包含的不同对象、跨领域非平凡性、是不是构造本身直接给出的事实。
- **非平凡程度**：原检测器的语义优先级、交会/切触/特殊心等较有趣结论、是否已经是作图定义的直接重述。

`scoreComponents` 保留两个评分部分。构造事实不是错误，仍保留并标记，只是默认排序更偏向独立发现。

## 7. 实验、兼容与限制

- 新增 `tests/v33.test.cjs`：**45 项断言**覆盖两种微扰模式、零坐标修改、反射/缩放的全等与相似顶点匹配、三种尺度的位置/方向/角度、远处离群点、正负点幂、平方长度与面积倍率、无关自由点恒等式、构造来源、蕴含索引和 12 点网格扰动。
- 既有 `v32_degeneracy` **63 项**、v3.1、v3、v2.2、Kernel、Pretty 等回归通过。
- 对18点、24点随机型几何大图在 `10⁻³`、`1`、`10⁵` 尺度做了相同扫描项目的试验。二次量检测采用更严格的独立相对阈值 `5e-11` 以避免大量随机组合下的偶然黄金分割比例。示例随机 18 点二次量未输出这种近似关系。
- 二次量包含三角形与点积候选，规模可能接近 O(n³)；**默认不自动选中**，需要时勾选，不限制完整结果条数。
- v3.3 不修改构造 Kernel，也不更改既有点/线/圆的几何位置。

**无法保证** 对所有图形、全部 1,447 道题库都没有数值误判或遗漏；微扰检查也不等于在构造自由度空间中严格证明关系。适合继续由用户进行大图交互验收。
