# GeomTool v5.3 — Pretty 条件约束下降

## 快速使用

打开右侧「作图关系 → Pretty」，在「几何约束条件」输入框输入一条条件并按 **Enter** 或 **确认**。编辑区会显示该条件是否被识别，只有验证通过的语法才加入列表。每条条件有独立删除按钮；在输入时会提示相关语法，并提供 datalist 模板。

添加条件后点击「计算 Pretty」：

1. 首先在可移动点的参数空间内，根据数值残差用阻尼 Gauss–Newton / LM 信赖域下降尝试满足全部条件。若初始构型退化或陷入局部驻点，会尝试可重复的确定性局部重启。
2. 跟踪符合条件条数最多、残差尽可能小的状态；若全部条件成立，再沿约束近似零空间的梯度方向细调布局，并利用校正迭代投影回约束集。
3. 仅在所有条件维持 `2e-6` 的归一化误差容限以内时接受美观阶段的步骤。为了防止退化，还保留 Kernel 的构造依赖关系与有效性检查。
4. 「沿下降路径移动」滑块仍在计算出的关键帧间移动；**优化的中间帧、局部重启过渡和任意百分比的滑块位置不保证满足最终全部条件**。最终 100% 位置是当前最优结果。

没有新增条件时仍调用原 v5.2 Pretty 求解过程，以保持兼容。

> **数值求解的限制**：不能数学上保证所有可行非凸约束总能被找到；存在相互矛盾的条件、固定参考点带来的不可能限制、几何退化、自由度不足时，会展示实际满足的条数与最大误差，不宣称全部满足。求解误差以归一化残差为准，未必直接等于屏幕上的绝对坐标误差。

## 可输入的条件

| 输入样例 | 含义 |
|---|---|
| `col A B C D`、`collinear(A,B,C)` | 3 点以上共线 |
| `cyc A B C D E`、`cyclic(A B C D)` | 4 点以上共圆 |
| `dist A B = d(C D) = 2 E F = sqrt5 *G H` | 距离相等、链式等式、倍数与平方根 |
| `A B / C D = E F / G H` | 线段距离比与复杂等式 |
| `ang(A,B,C)=90`、`angle A B C D = pi/2` | 三点无向夹角、四点有向直线夹角、度/弧度 |
| `ang(A B C)+ang(D E F G)=90` | 角度加减乘除、角度之间的等式 |
| `perp A B C D`、`para l (A,B)` | 直线垂直或平行 |
| `tangent(c1, c2)`、`tan c l` | 两圆或圆与直线相切 |
| `para c l`、`perp l c`、`perp c1 c2` | 圆线相切；线经过圆心；两圆正交 |
| `A in c`、`subset(A,l)`、`sub A c(B C D)` | 点位于直线或圆上 |
| `cong A B C D E F`、`simtri (A B C) (D E F)` | 按列出的顶点顺序全等 / 相似 |
| `cong A B C D` | AlphaGeometry 风格的两线段等长 |
| `area A B C = S(D,E,F)`、`(A B)^2 = 5` | 面积和线段的平方 |
| `eqangle A B C D E F G H`、`eqratio A B C D E F G H` | AG 谓词风格的角相等 / 比相等 |
| `aconst A B C D 90`、`rconst A B C D 1/2` | AG 谓词风格的角常量 / 长度比常量 |
| `midp M A B`、`onl A l`、`onc A c` | 中点和归属语句 |

支持的点/线/圆对象名必须是当前画板中有效的对象标识符或标签。`(A B)`、`(A,B)` 代表经过两点的直线；`(A B C)`、`c(A,B,C)` 代表经过三点的圆。标量上下文中 `(A B)` 表示线段长度。角度表达式中 `ang(A,B,C)` 为顶点 B 的无向夹角，`ang(A,B,C,D)` 为 AB 到 CD 的有向角。角度裸常数超过 `2π` 时按**度数**解释；带 `pi` 的数值按**弧度**解释；无 `pi` 的较小常数按弧度。建议始终用 `pi/2` 或 `90` 避免歧义。

不支持任意 JavaScript、动态变量、三角函数或外部脚本输入。特殊名字若与保留算子 `d`、`S` 等重合时建议使用显式函数括号。

## AG2 编译与证明边界

在运行 **AlphaGeometry 2** 前，会对当前有效条件逐条重新做数值精度检查，再尽量映射为 AG2 官方可接受的谓词，例如：

- `coll`、`cyclic`、`cong`（长度）、`para`、`perp`、`eqangle`、`eqratio`、`aconst`、`rconst`；
- 部分点归属、三角形全等和相似的分解谓词；
- 有圆心和半径见证点时的圆上归属、经过圆心的直线垂直于圆的条件。

三点无向角会转换成与当前数值图形同向的四点有向角形式；长度与角常量仅在可安全表示为小分母有理数时转换。复杂角和、非有理比例、一般圆的相切或正交等 AG2 原生输入不能无损表示的条件，仍参与 Pretty 数值约束，但在「尚未精确表达的条件 / LIMITATIONS」中说明，**不会悄悄伪装为可证明前提**。链式等式会尽可能逐段转换，并报告其余无法转换部分。

用户提交的谓词以 `USER-PRETTY:<原语句>` 作为 `source`，和 **构造定义产生的形式前提** 区分。它们是用户主动声明且数值检查合格的 **附加假设**，而不是被 AG2 或 Pretty 自行证明的结论；不能从条件成立的浮点图就声称得到一般数学定理。

AG1 原生推理没有自动引入这些附加假设。运行 AG2 时，在「查看提交 AG2 的点坐标与几何条件」中可查看原样提交的谓词及来源。对于当前达不到精度的条件，绝不注入 AG2 假设列表。

## 持久化和测试

添加的条件文字随浏览器工作区自动保存，也随 `.geom.json` 导入导出。替换新图/载入题库图将清除上一张图的条件。修改几何对象后可再次优化；被删除的点将导致相关条件显示为「对象无效」，需编辑或删除该条件。

回归测试：

```bash
node tests/v53_constraints.test.cjs
node tests/v51_compilation.cjs
node tests/v52_new_constructs.cjs
node tests/v47_numeric.test.cjs
```

浏览器通过交互测试（含回车确认、删除条件、点击 Pretty、验证 3 条条件同时收敛、无 JS pageerror）。原项目中部分早期 `v2` / `v43` 测试引用 v5.2 已删除或改变的旧接口，不适合作为 v5.3 完整回归断言。本次未在受限环境中运行完整 Pyodide AG2 Worker 证明过程；已测试 JS 侧 `DDAR.prepare` 中的用户前提注入和未满足条件过滤。
