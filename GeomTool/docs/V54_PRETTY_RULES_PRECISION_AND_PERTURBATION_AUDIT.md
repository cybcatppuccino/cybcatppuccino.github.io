# GeomTool v5.4：Pretty 语法、公理提交、数值精度与扰动审计

## 核心设计

- `?` 是输入框右侧唯一的帮助入口：打开/折叠七条完整规则，输入时不再自动浮出提示，也不再使用 HTML datalist。
- 每次提交一个条件。Enter 与「确认」调用同一个解析器。有效语句加入可删除列表；无效对象名、参数数目、量纲不兼容等给出错误。所有文本在自动保存及 `.geom.json` 中保留。
- 所有条件优先于美观。`Pretty.optimize()` 只修改从序列化内核得到的临时副本，调用者点击「计算 Pretty」后才通过 `Pretty.apply()` 更新画板。
- 优化目标 `5e-13` **归一化残差**，对一般条件进一步进行精细牛顿抛光，**可能**获得 `~1e-15` 或更小值；实际限制为 IEEE-754 双精度、条件数、退化程度及可移动自由度。扫描器阈值另按局部几何尺度、距离/角度/比率分别定义，不能简单等同于归一化误差。
- 较难、无解或自由度不足的约束系统不会虚报成功，显示达到目标条数和最大误差；关系检索数值发现、用户给出的 AG2 前提与经 DDAR 正式证明的结论严格区分。

## 完整语法归纳（七条）

1. **对象和记号**：当前画板有效的点 `A`、`B`；直线 `l`、`(A B)`、`(A,B)`；圆 `c`、`(A B C)`、`(A,B,C)`、`c(A B C)`。无现存整体同名点时，大写单字母紧连 `ABC` 可以拆分。`(A B)` 在标量表达式中是长度，在载体表达式中是直线。`c(A,B,C)` 要求三点唯一确定圆。
2. **归属、共线、共圆**：`col A B C D`、`collinear(A B C)`、`coll A B C`；`cyc A B C D E`、`cyclic(A,B,C,D)`；`A in c`、`subset(A,l)`、`sub A c(B C D)`、`onl A l`、`onc A c`；`midp M A B`。共线至少三点，共圆至少四点。中点语句分解为共线与两段等长。
3. **两载体关系**：`perp A B C D`、`perpendicular(l,(A B))`、`para l1 l2`、`parallel(A B)(C D)`、`tangent(c1,c2)`、`tan c (A B)`。线线：垂直/平行；圆线：`perp` 表示过圆心，`para` / `tan` 表示相切；圆圆：`perp` 表示正交，`para` / `tan` 表示相切。两条直线之间不能使用 `tan`。
4. **可计算量与等式**：`dist A B = distance(C,D)`、`d(A B)=sqrt5*E F`、`(A B)^2+(B C)^2=(A C)^2`、`A B / C D = E F / G H`、`area A B C = S(D,E,F)`。支持链式等号、加减乘除、乘方、`sqrt(5)`、`sqrt5`、`pi`、括号、省略乘号。有量纲的加减只能在同类量之间；常数可直接赋给相应量。幂指数仅接受常数算式，禁止将几何比率误当幂指数。
5. **角度与角式**：`ang(A,B,C)` 取 0–π 的无向角（顶点 B），`ang(A,B,C,D)` 是 AB 到 CD 的有向角。`angle` 同义。`ang A B C D = pi/2`、`ang(A,B,C)+angle(D,E,F,G)=90`、`ang A B C D = 2 ang R S T U`。显式 `90°` / `90deg` 为度，`pi/2` 为弧度；为兼容 v5.3，裸数字绝对值大于 2π 时视为度，否则为弧度。角式残差按 2π 周期求最小差，因此有向角等式允许整周等价。
6. **三角形关系**：`cong (A B C) (D,E,F)`、`cong A B C D E F` 表示 ABC↔DEF 顺序全等；`simtri(A,B,C)(D,E,F)`、`sim A B C D E F` 表示按顶点顺序对应的相似。`cong A B C D` 兼容 AG 风格的线段 AB=CD。禁止三角形重复顶点，数值求解增加非退化限制。
7. **AG1/AG2 风格谓词**：`eqangle A B C D E F G H`、`eqratio A B C D E F G H`、`aconst A B C D 90`、`rconst A B C D 1/2`、`midp M A B` 等。只把当前**已数值满足**且能用 AG2 正式谓词无损描述的用户声明附加到 AG2 前提，来源 `USER-PRETTY:`；其余只影响 Pretty 并记入 limitations。AG1 不偷偷引入 Pretty 的用户声明。

解析器是受限数学表达式解析器，**不执行 JavaScript**。语法不支持任意函数、量词、布尔逻辑组合、条件分支或自定义代数未知量。

## 优化策略 v5.4

1. 参数化可移动点，保持 Kernel 构造依赖关系，拒绝使已有效构造变无效的试探。
2. 利用阻尼 Gauss–Newton/LM 求解归一化残差，采用自适应正则与回退搜索。损失改进门限不再停留在约 `1e-8` 残差。
3. 若目标接近可行，再用五点中心差分导数与高精度牛顿步精修；目标 `5e-13`，理想情况下可至机器精度。
4. 在达到约束目标的前提下沿近似切空间做美观下降，投影回约束。只接受同时保持条件满足的帧。
5. 陷入退化局部驻点时，可在**临时副本**中确定性重试多起点；只在点击 Pretty 后提交最后结果。滑块中间帧（含重启间过渡）不保证约束全部成立，应以 100% 的终点检查和证明前提校验为准。
6. 最终 AG2 注入采用**独立的、更严格** `2e-10` 归一化误差门槛；不能表达的条件显示限制，不冒充数学证明。

共圆改为归一化四点行列式（消除旧版三点外接圆心相减的数值不稳定），并对定义三点的退化情况加入非退化条件。也对共线首两点重合、三角形退化增加显式检查。

## 扰动来源逐项审计

| 路径 | 默认行为 | 画板是否被暗改 |
|---|---|---|
| 关系扫描复验 `radar-perturb` | **关闭**，勾选后在独立快照正负两次小扰动，只剔除不稳定候选 | 否 |
| 条件 Pretty 的求解起点重启 | 必须主动点「计算 Pretty」；仅在内部 Kernel 副本中尝试并只提交计算结果 | 不会因后台重启而改画板 |
| AG1 重合点通用示意 | v5.4 **默认拒绝自动替换**并给出解释性错误；只有开发者显式 `allowGenericRealization:true` 才允许在副本中尝试 | 否 |
| AG2 用户约束 | 只采用当前画板精度达标且能表达的已添加条件 | 否 |
| 关系检索（微扰关闭） | 仅计算，不写 Kernel 坐标 | 否 |
| 无初始坐标题库的「载入构造并自动 Pretty」 | 按按钮标注，先在试算副本自动整理图形，再由用户确认载入；有源坐标的图不改原坐标 | 是，用户触发题库载入 |
| 交互作图、拖动、滑块、Pretty 提交 | 明确的用户操作，会修改构图并进入历史记录 | 是，用户触发 |

此外，几何构造分支、吸附和渲染使用既有 Kernel 行为，本次未更改它们的数学定义。审计范围是程序中识别出的显式 `perturb` / `jitter` / `random` / 通用数值示意路径，并非对所有可能的外部浏览器扩展或数值误差给出形式正确性证明。

## 数值与回归检查

执行：

```sh
node tests/v53_constraints.test.cjs
node tests/v54_precision.test.cjs
node tests/v54_ui_static.test.cjs
node tests/v51_compilation.cjs
node tests/v52_new_constructs.cjs
node tests/v47_numeric.test.cjs
```

典型可满足条件：2/3/4/5 条，分别获得约 `0–2.8e-16` 的最大归一化误差；包含共线、垂直、等长、长度 2:1、平行的 5 条条件对 60 个不同初值，60/60 次均降至 `4.4e-16` 以下。共圆+圆线相切在当前测试样例中同时降至 `~1e-15`，关闭微扰的探测器发现了 `concyclic` 和 `circleLineTangent`；其他例还检出了共线、垂直、平行和长度比。

**边界**：

- 测试通过不意味着所有构型必可达 `1e-15`：不可能条件、近退化、强耦合、大尺度/极端小尺度、无自由参数等均可能中断。请参考逐项误差，不要只看总状态。
- `AG2` 作为形式推理器能否证明某个具体目标，依赖所提交谓词和官方推理规则，与 Pretty 数值达标不是同一个命题。本版验证 JS 编译、注入以及数值扫描，没有声称完成全部 Pyodide / AG2 原生 Worker 端到端证明。
- Chromium 浏览器在本次执行环境受到管理员导航策略阻止，无法完成 v5.4 的页面端到端交互验收。已做 JS 语法、HTML 结构、Node 几何及关系回归；实际浏览器应再验收一次 `?` 展开、确认/Enter、列表删除和滑块。
