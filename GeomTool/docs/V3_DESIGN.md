# GeomTool v3：几何行为、关系引擎与状态设计（历史文档）

> v3.1 关系检测与类别数字以 [V31_RELATIONS.md](V31_RELATIONS.md) 为准；下文保留 v3 当时的行为说明。

v3 是 v2.2 的离线静态版本升级，保留 `geomtool.ir/v1` 文件协议、Pretty、工具示意、专家证明界面与原 1,447 条题库。以下用于说明确切语义和已知边界；「关系发掘」始终属于**数值候选**而非严格证明。

## 1. 选择 / 拖动

在「选择 / 移动」工具中，主鼠标按下时会在**有效、可见、非系统参考对象**中优先搜索 `free / real / onLine / onCircle` 四种活动点（距离光标中心不超过 15 CSS px）。同一区域若有直线、圆、不可移动派生点或多边形，仍优先拖动最近的活动点；距离极近时先看此前选中的活动点，避免操作抖动。拖动过程中只更改 Kernel 的活动点参数并重算依赖；结束时合并为一次撤销记录。若附近无可活动点，点击选中任意可见对象，拖动则平移背景。空格拖动或鼠标中键强制平移。

## 2. 相交分支的拓扑槽位

**几何不随屏幕方向或点选顺序重新编号。**交点的两个分支存为 `params.branch = 0 | 1` 和 `params.slotVersion = 3`。交点载体先规范化：直线/射线/线段排在圆前，两条同类载体则按稳定对象 ID 排序。

- 两圆：对于排好序的中心 `O₁,O₂`，将两个交点按相对有向中心向量的叉积符号分到固定槽位：`0` 是负侧，`1` 是正侧。
- 线圆：沿直线的**有向参数 t 从小到大**排两个根。即使只是射线或线段，仍保留相应根的原槽位：不满足区间约束的槽位为 `null`，**不得将原第二根压缩为第一根**。
- 线线：唯一解只有槽位 `0`。圆或线发生切触/重合等退化时，相应分支暂时无效；恢复正常几何位置后，按原定义重现，不会自动把原分支换成另一支。
- 为其他工具与旧文档保留 `intersections()` 的「有效交点紧凑列表」，派生 `intersection` 节点本身使用新 `intersectionBranches()`。载入旧 v2/v2.1/v2.2 节点时，若缺少 `slotVersion`，会根据旧结果的实际坐标映射到 v3 的固定槽位，并保持旧图已有的交点位置。新导出的文件持久化 `slotVersion`。

注意：如果两根在数学上真的于切点重合，严格来说不能显示成两个不同坐标；v3 的第二分支此时会暂时无效，这是防止伪造两个不同交点的刻意选择。若被依赖的载体退化为完全重合、或者有向线本身因两个定义点重合而失效，依赖节点会暂时失效，而不会偷偷改选另一根。

## 3. 两个显示按钮的状态模型

`settings.axes` 表示用户**独立要求**显示坐标轴；`settings.complex` 表示用户**要求**显示完整复平面参考。坐标轴复选框的**外观**是两者的逻辑或，显示的对象区分为两组：

| 独立 axes | complex | 设置中「坐标轴」指示 | 可见系统对象 |
| --- | --- | --- | --- |
| 关 | 关 | 关 | 无 |
| 开 | 关 | 开 | 实轴、虚轴、原点 |
| 关 | 开 | 开（由复平面临时请求） | 实轴、虚轴、原点、1、i、单位圆 |
| 开 | 开 | 开 | 实轴、虚轴、原点、1、i、单位圆 |

打开或关闭复平面**只修改** `settings.complex`，因此关闭时会恢复原来的轴偏好。用户若在复平面开启期间点击「关闭坐标轴」，将同时关闭复平面，避免出现勾选关但坐标轴仍存在的矛盾状态。清空画板只清除作图依赖，不修改 `axes/complex`；系统参考对象自动恢复。各系统参考对象不能被单独隐藏以破坏组开关的保证，但保持可选择、可作为点、线、圆构造输入。

## 4. 复数方程

选择点：显示 `z=x+iy`、共轭、模和幅角。

选择直线：对方向 `d=(dx,dy)`，取单位法向量 `n=(-dy,dx)/|d|` 并固定整体符号，定义 `α=n_x−i n_y`（因此 **`|α|=1`**），显示规范方程

`α z + conjugate(α) conjugate(z) + c = 0`, `c = -2(n·p)`。

选择圆：以 `a=c_x+i c_y` 为圆心复数、`r` 为半径，显示

`z conjugate(z) − conjugate(a) z − a conjugate(z) + |a|² − r² = 0`。

系数按照用户小数精度显示；默认 3 位，可选 0–15 位。显示的是当前几何位置对应的**数值系数**，不是一般几何命题的符号式恒等变形。

## 5. 关系发掘：几何支撑线规范化

`assets/relations/core.js` 从显示的点自动生成所有不同点对 `AB` 的隐含支撑线，并导入显式的直线/射线/线段。检测核心按方向与有向点线距离的共同容差，把**几何上共线**的各种表示合并为一个支撑线家族。`parallel`、`perpendicular`、等角、圆线相切等判定只在规范化的线家族上进行，去掉「AB 与 l 平行」、「AC 与 l 平行」却都表示同一条底层直线的重复项。

仍保留显式线段、射线的原始范围：判断 P 在线段上时，P 必须位于实际区间，不因为支撑线合并而把无限延长线当成原线段。别名会在名称中适度列出，使 `AB、BC、CD、l` 等描述可以搜索到相同几何关系；保留全部数值搜索结果，UI 以每批 80 条分页避免一次产生过多 DOM。

v3 注册表现在有 **53 类**，在原 41 类基础上新增 12 类：互余角、互补角、角度常见比例、同圆等弦、根轴、三角形面积比、垂心组、欧拉线、九点圆、等腰梯形、三角形内切圆、割线幂。已有「等角」类别同时搜索三点角以及“两条已有或隐含线构成的夹角”，无需额外勾选。对于两线夹角，若交点在可视范围内，标注器还会显示小夹角的临时角弧；AB/CD 未在图中画出也会临时补绘。

搜索框以空格、英文或中文逗号、顿号和分号拆分多个关键词，**所有关键词须同时匹配**（AND），匹配字段包括关系中文类别、结果描述、详细信息，以及标记中的对象 ID/标签；常用别名（如「互余」「垂线」「等长」）做一定程度的归一化。搜索可见对象仍是默认行为；显示坐标轴/复参考时对应对象自然加入候选，手动勾选「搜索隐藏对象」时纳入有效的隐藏对象。

## 6. 变换表达式

`assets/expression.js` 提供**不执行任意 JavaScript** 的小型数学表达式解析器，支持：十进制和科学计数数值、括号、单目正负号、`+ - * / ^`、`pi/π`、`e`、`sqrt(...)`、`sqrt2`/`√2`。拒绝无效字符、未知符号、括号错误、非有限结果和过大数值。

位似点：表达式算出位似比 `factor`。旋转点：可选直接输入「度」或「π 的倍数」；若后者填 `5/7`，对应弧度为 `(5/7)π`，Kernel 保存的旋转角度为 `180*(5/7)` 度。原始表达式与输入单位作为附加参数存档，不影响旧 Kernel 的纯数值构造能力。

## 7. 边界与验证

数值检测会使用容差，不是数学推导。接近退化的图形、数量很大的点阵或高度对称图可能发现非常多的候选关系，运算和浏览器内存消耗会增加。v3 未对完整离线题库的所有实例、所有连续拖动路径或大型组合进行穷举验收。测试包含独立 Kernel/Pretty/关系回归、小型 v3 断言（根槽位、旧图导入、公式与关系）以及一次浏览器 UI 烟雾检查（状态开关、复方程、重叠点拖动、关系面板）；后续主要使用验证交由用户。
