# GeomTool v5.2 — 相似点、等角线与 AG2 溯源

## 构造

- **相似点**：`similarpoint F A B C D E`，对应 `A→D, B→E, C→F`，使用同向欧氏相似变换（复数乘法），非共线和三点共线、但 `A≠B` 且 `D≠E` 的实例均有效。`ABC` 或 `DEF` 共线时相应的非零向量关系仍能表达。`A=B,D≠E` 没有满足指定对应的相似变换，拒绝构造；`A=B,D=E` 非唯一，给出规范代表 F 并且**不**宣称经典三角形相似的形式前提；`A≠B,D=E` 比例为零，生成 F=D 但不注入通常的非退化相似假设。
- **AG2 输入**：相似点的三组非退化对应角相等 `eqangle`、三组独立的非退化对应边比例 `eqratio`（其中一部分可能与其他条逻辑冗余）；内部构造不引入不受控的非有理比例常数 `rconst`。任何退化角/零长度边不构造对应的不适用谓词。
- **等角线**：`equalangleline l A B C D E`。沿输入顺序取 `∠ABC=(BA→BC)`，以 `ED` 为初始射线旋转该有向角生成 `EQ`，直线经过 E。内核为其生成虚拟点 `@line:l:1`，提交 `eqangle B A B C E D E @line:l:1`。模 π 的有向线夹角已在前提编译器中进行数值一致性检查。
- 两个新操作均支持画板拖点更新、撤销、存档以及直接从命令行调用。新线载体依旧仅在提交 AG2 时建立临时点，不加入画板对象树。

## 可审计日志

`vendor/alphageometry2/geomtool_v45_session.py` 的单次推理日志依次记录：

1. `INPUT`：原封不动保存坐标、辅助点、全部构造谓词、目标。
2. `PREMISE`：每条正式输入谓词各自有稳定编号。**这些是证明根节点，按逻辑定义没有父结论**。
3. `EQUATION`：由输入谓词产生的正式初始线性方程；指向对应 `PREMISE`。
4. `DD_APPLY`：几何定理实际应用（目前特别针对 AA/SSS/SAS/SSA 相似），记录匹配的两个三角形、检查为真的角/比例命题、消元父方程引用、所用判定；SSA 额外保留数值消歧警示。
5. `AR`：新插入线性消元器的方程及源编号；`ElimCore` 保存主元方程引用，当替换、消元时建立间接依赖。**不改 Gaussian elimination 本身、返回值或数值判断**。
6. `DD`：其他原生几何结构操作的日志事件，记录规则、具体原始关联性质及可定位的来源；如无法找到逐条直接父结论，则用**全部源前提**作保守宏级依赖，标记 `complete=false`。
7. `DDAR`：原生 `check_pred` 真正确认的已证目标，尽量附上精确代数主元来源编号；结构谓词只可给宏级追溯时明确说明。

特别说明：**“所有派生结果必须具有来源”不同于“所有推理已获得完整的最小公理级 DAG”**。精确高斯主元依赖及相似应用在可检查时以编号连接；圆、共线归并、顺序、数值分支等不能无损还原的部分有宏级证书及日志警示，不伪造一个未被引擎使用的直接父命题。因为源码含坐标消歧，这也不是独立于构型的纯公理证明验证器。

## 用户交互

- “查看 AG2 推理日志与前提引用”按钮在两个推理动作下方。支持刷新、复制；原 `下载 AG2 推理日志 (.jsonl)` 仍保留完整、逐行可机读的运行轨迹。
- 点击已证结论打开原生重放验证及依赖回溯。代数可追溯目标优先展示从目标方程反向递归得到的依赖 DAG，并在界面转成人类可读的平行、垂直、相似三角形、长度与角度关系；点击可高亮能与真实画板对象对应的点和线。对于无法精确还原的证明，仍使用原生重放宏证书。
