# GeomTool v3.2 · 关系发掘的去平凡化与扰动稳定性

## 目标与数学边界

关系发掘现在采用四级过滤：`groups.js` 几何归并 → `triviality.js` **候选生成阶段**拒绝内禀/退化关系 → `detectors.js` 严格数值判定、角度等价簇与三遍微扰复验 → `semantic.js` **跨类别**蕴含消冗。`search.js` 继续处理结果别名与比值反演。这样无需生成数万条明知平凡的结果后才清空界面。

严格数值模式保持。距离、方向、比例阈值仍为相对 `1e-9`；角度阈值由 v3.1 的 `1e-6°` 收紧为 **`3e-8°`**。距离阈值继续参考鲁棒局部几何尺度，避免远距离离群点放松检验；两次带确定性种子的正、负微扰复验不变。严格数值和短程扰动不能等同于使用构造依赖/符号定理进行形式证明。

**一个必须明确的边界**：当一个点确实离开正好共线、共圆、垂心等约束子流形超过容差时，数学关系就真的消失，即使视觉上只移动非常小的距离，也不能为稳定计数而强行认为这些关系仍然精确成立。v3.2 所消除的是由于同义表示、数值宽松及生成对象交会导致的*虚假新增*，不是否定真实几何变更。

## 去平凡化规则

| 发现的假条件或冗余 | v3.2 的策略 | 仍会保留的例外 |
|---|---|---|
| 已命名点 K 在圆 c 上，AK 与 BK 交于圆 c 上 | 两线交点若已被命名且该点在 c 上，拒绝重复的交会报告 | 未命名的真实两线交点位于圆上，仍报告 |
| 已命名公共点在两圆上、又在某线 | 点-两圆-直线已有的入射事实足够，拒绝虚假的新公共弦 | 未命名的一个或两个交点落在指定线上仍报告 |
| 三圆公共点已命名 | 不再将其计为独立三圆未命名共点 | 未创建的三圆共点保留 |
| A、B、C 共线导致 ⊙(A,B) 与 ⊙(B,C) 相切 | 两个虚拟圆共用定义点或切点等于任一圆的定义点时过滤 | 四个定义点相互独立、非锚点处相切仍可报告 |
| 虚拟圆 ⊙(A,B) 与过 B 的垂线相切 | 圆的定义半径 AB 已垂直给定直线，因此不是另一独立条件 | 切足不在任一定义半径点上的真实切线保留 |
| 切点与定义半径点**非常近**却未真正重合 | 使用 `sqrt(2 r ε)` 级接触保护带，防止二阶误差 `O(δ²/r)` 被线性公差误收 | 与定义半径端点明确分离的非平凡相切保留 |
| 角 ABC+角 DBC=90° 因已知 AB⊥BD | 比较线方向族，排除由已有直角被一条额外射线拆分的恒等式 | 不能由共用方向/已知特殊角解释的互余角仍保留 |
| 同角、互余/互补/比例的数百种点或线刻画 | 首先把方向对及顶点角按度数聚类，用一个连等/连比代表每个角度族 | 方向不同但角度真实相等仍保留为独立等角族 |
| 双线的不同平行副本表示同一角 | 先将支撑线归并为方向族，方向对相同不再计为新的等角 | 两组不同方向对仍存在真实等角关系 |
| A 是 BCD 的垂心与 B 是 ACD 的垂心 | 四点共成一个“垂心组”，抑制四项重复“特殊点＝垂心” | 三角形中心若同时承担外心/内心等不同角色仍显示复合角色 |
| A、B 关于 CD 轴对称，同时 △ACD ≅ △BCD | 已经有对应全等组时，用全等组承载对称别名，不独立计数 | 仅勾选轴对称时独立结果仍可查询 |
| 正方形四顶点共圆，以及顶点 90° 旋转 | 最具体正方形事实承载其逻辑推论及搜索别名 | 圆另含其他点或旋转涉及独立中心时，保留额外关系 |
| 全等三角形等面积 | 如果整条等面积簇完全包含于同一全等簇，则只显示全等 | 等面积簇含非全等三角形时仍保留 |
| 直角三角形的一条边被重复当作“高线” | 如果只承担“高线”角色并且垂直关系已启用，不重复记录 | 同时兼任中线/角平分线等高级复合角色则保留 |
| 圆上半径相等、自然线段等长 | 不因其平凡而彻底删除：整簇等长只显示一条 | 任意对等长段仍可通过簇的别名检索 |

> **刻意不做**：无法形式证明蕴含关系的候选，不凭表面相似而一律删除。例如不独立的特殊切触会删除，但真实未命名切线保留；非退化交会不因“可能由更深定理推出”就被武断删去。

## 代表性高退化图与扰动对比

**共用测试图**：四列三行共 12 个规则网格点，步长 2；额外圆 `c` 圆心 `(3,2)`、半径 `√2`。两个版本使用完全相同的对象、可见性、默认 50 类规则及比较扰动：将 `P11` 改为 `(x+δ,y+0.3δ)`。

| --- | ---: | ---: |
| 基准图扫描后保留关系 | 40,283 | **989** |

## 测试用例

`node tests/v32_degeneracy.test.cjs`：63 项断言，包括 40 多种独立场景/断言及 12 个无特殊几何关系的自由点位置、非退化与伪切线、未命名交会、点命名后去重、重复圆/直线、重合点、正方形蕴含、两圆公共弦、三圆共点、随机位置引发的假互余、12 点压力图的三档 `1e-12/1e-11/1e-10` ID 集合完全不变，以及 `1e-8` 下的合理变动。

兼容回归包括 `tests/bootstrap.test.cjs`、`kernel.test.cjs`、`v2.test.cjs`、`v22.test.cjs`、`v3.test.cjs`、`v31.test.cjs`、`v31_semantics.test.cjs`。旧版测试中的“圆以半径端点为切点且直线过端点”的期望依照 v3.2 的去平凡规范，替换为非端点切足的真正非平凡切圆样例。原几何 Kernel、Pretty、1,447 条离线库索引不改。

**性能说明**：没有进行全部题库的穷尽扫描。隐含点对线、三角形、四边形的组合规模随点数增长很快；特别大的点集依然可以产生大量*数学上真实*的不同关系，默认不做结果数量硬截断。用户可以在扫描前勾选需要的关系类别来减少计算。

**不保证**：这不是全自动几何定理证明器，不具有所有同义几何关系的完备推理能力；候选可能剩下某些更深层的逻辑蕴含，对病态尺度、接近切触及正好位于容差边界的高阶退化仍存在双精度限制。
