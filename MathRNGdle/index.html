How rarity works

Number Rarity

Your roll is ranked against all 1,000,000 possible integers from 0 to 999,999.

TrashBottom 1%
CommonBottom 50%
UncommonTop 50–25%
RareTop 25–10%
EpicTop 10–5%
AnomalyTop 5–1%
MythicTop 1%

Jackpot: Mythic results in the Top 0.1% receive a Jackpot banner; the Top 0.01% receive Ultra Jackpot status with an exact rank.

Random rolls: each integer from 0 to 999,999 has exactly the same probability. v11 uses Web Crypto with rejection sampling, so there is no modulo bias and no silent Math.random fallback.
