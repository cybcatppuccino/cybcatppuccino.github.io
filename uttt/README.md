# UT³ APEX V14 · 终局证明协同搜索（差分升级）

**V14 是搜索引擎升级，继续使用 V13 的 Stage2 FP16 网络权重。**
这份差分补丁需覆盖解压到原版 `uttt/` 目录，不单独包含全部静态资源。
保留原 `apex.wasm`、`stage2.fp16.gz`、Stage2 推理 WASM、游戏规则以及原有普通模式；机器学习开关默认开启的原设置逻辑不变。

### V14 搜索改进

- `worker.js`：中盘混合搜索改为跨迭代的**滚动墙钟时间公平队列**，PUCT/PVS/独立证明根据当前结构、搜索成本、证明收益实时调节；有限时长和无限分析使用相同的调度器。耗时分别计入 `puctWallMs`（包括 PV 侦察的推理）、`pvsWallMs`（包括 PVS 内 Oracle）和 `proofWallMs`（独立 AND/OR 证明）。另单独报告 `pvsInternalOracleNodes` 与 `scoutWallMs`，因为无法仅通过原 WASM 接口精确分离内部 Oracle 的墙钟时间。
- `proof_scout.js`（新增）：沿神经策略/MCTS 主变化增量地展开数步，间歇探测有可信度的次要应手。用结构收缩、分支变窄、证书的部分成果与耗时反馈确定优先级，未知着法不被视为失败。每次调用少量推理，避免无限分析一开始的巨大探索尖峰。
- `stage2_mcts.js`：为每个 MCTS 节点保存严格 WDL 下界/上界。单侧不能强制获胜仅提供一侧界，双侧反证才是严格和棋；严格界通过子节点取负后逐层极大极小传播。允许跳过严格上界已低于父节点可保证下界的分支；禁止使用神经价值冒充严格证书。
- `app.js`：一侧证明显示为 `X≥D`、`X≤D`（或 O），不再仅用模型百分比覆盖此类严格信息，候选顺序优先已证明的安全着法。
- `tests/v14_proof_bounds.test.mjs`：包含严格证书传播、单侧反证、深层和棋不得误证根、已证明必胜优先，以及无限分析比例公平性单元测试；运行 `node --test tests/v14_proof_bounds.test.mjs`。

**说明：** V14 不改变 C 证明算法本身，完成 WDL 的可靠性由原证明器保证。短时模式首次启动仍受 Stage2 网络加载时间影响。验证了单元测试和少量 WASM/Worker 对局局面，但尚未进行足以证明净 Elo 提升的成规模配对自对弈，不应将个别局面的改进等同于统计棋力提高。

# UT³ APEX V13 · 全主干训练增强版（精简交付）

**这是完整可运行的游戏与 AI 引擎**，只去掉了旧版本模型权重、上百 MB 训练检查点和大量原始训练素材。最新 V13 模型默认启用；游戏搜索器与 V12 稳定版一致。所有 200ms 对局均开启神经网络增强。

## 一键运行

- Windows：双击 `start_windows.bat`。
- macOS / Linux：`sh start_mac_linux.sh`，在浏览器打开 `http://localhost:8080`。
- 或在 `web` 目录执行 `python3 -m http.server 8080`。

浏览器必须支持 WebAssembly SIMD（会回退 scalar WASM）、Worker 和 gzip `DecompressionStream`。不能直接双击 HTML 使用 `file://`。

## 本次训练

- 从首次发布的 V13 权重开始，**4,795,265 个参数参与反向传播**（卷积主干和策略部分）；价值专用解码器保持冻结。
- 10 个完整 epoch，每轮 55,407 个训练局面（36,769 个搜索监督、18,638 个 MCTS 能力保护），共约 554,070 次样本输入。
- 未融合的完整主干训练检查点明显损害原 MCTS Top-1，因此不采用。
- 选择第 **10** 轮主干更新按 **10%** 与初始 V13 权重融合：独立保留集 MCTS Top-1 较原版多对 **5** 个，10–20 手多对 **0** 个（持平），中盘多对 **6** 个；搜索分歧集多对 **225** 个。
- 标签来自有限深度搜索，不等于数学最优。以上验证集改善很小，不可据此推断统计显著棋力提升。

80 个固定的第 10–20 手开局，分别与两个对手交换 X/O，各 160 局；赛前冻结权重。**独立逐着验证 320 局、12,237 手全部合法，7,844 回合实际进入神经网络搜索。** 样本胜率正向，但置信区间仍跨 50%，所以不能保证每个时间档都不退步。

## 本精简包包括

- `web/`：完整网页、WASM 搜索器和网络、当前 Stage3 FP16 权重（已经启用）。
- `src/`：完整 C 搜索与 WASM 网络推理源码，附构建脚本。
- `training/`：关键训练脚本、10 轮损失与验证日志、融合选择结果、数据来源统计。**不含重新训练所需的全量数据和 20MB PyTorch 权重**；重新训练需自行提供首次 V13 权重与原训练 NPZ。
- `results/`：320 局逐局统计、全部逐着棋谱、开局固定清单与独立合法性结果。
- `tests/`：简化的模型推理校验、规则测试和 Worker 快速运行测试。

### 模型切换

体积限制内**只打包当前最优融合模型**。`python switch_model.py verify` 可以查看当前文件哈希。要安装自行提供的兼容 FP16 模型：`python switch_model.py install /path/to/weight.fp16.gz`，无需重新编译 WASM。原版 Stage2/原始 V13 权重不在这个精简包中。

运行 `sh tests/run_light_tests.sh` 可以执行精简包内的功能自测。
