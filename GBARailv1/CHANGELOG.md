# Changelog

## v2.1 — 2026-08-01

- 修正“精简”和“无信息”模式残留的底图白色图标框：隐藏被抑制文字对应的完整符号图层。

## v2 — 2026-08-01

- 修正有轨电车与轻轨线路色优先级，具体线路标识色不再被通用分类色覆盖
- 无明确线路色的共线轨道改为中性底层，服务线路颜色保持在最上层
- 地铁默认改为纤细直线
- 重做底图文字层级控制，并增加“无信息”选项

## v1.2 — 2026-08-01

- `rail_snapshot.geojson` 继续作为绝对首选数据源；本地服务器改为多线程并支持即时 gzip 传输，原始 GeoJSON 不变。
- 快照首载采用批量缓存和延迟搜索索引，减少同步处理与重复复制。
- 优先保留快照中有轨电车、轻轨及其他服务线路的已有标识色；样式控件不再影响主线颜色。
- 建设中点线新增线段长度、间距和端点形状调节。

## v1.1 — 2026-08-01

- `rail_snapshot.geojson` 改为启动即预取、优先解析，并与底图并行加载。
- 国铁与高铁统一使用红色系；新增五类线路样式控件。
- 建成线路保留连续主线，建设中线路默认点线并可切换虚线样式。
- 降低线路粗细和站点大小滑杆下限。

## v1 — 2026-07-31

- 移除站点显示模式、自适应聚合及聚合阈值控制
- 修复线路粗细、透明度和站点大小调节
- 增加多种站点图案
- 增加底图对比度、饱和度和信息层级控制
- 统一普通与全屏底图外观
- 补充城际、轻轨及建设中线路标识色，未知建设线路使用灰色

## v0.3 — 2026-07-31

- 精简侧栏为轨道图层、底图风格两大模块
- 增加桌面/移动侧栏收起与展开
- 默认简洁底图；移除夜间模式
- 增加底图透明度、灰度控制
- 轨道叠加层始终置顶
- 新增站点聚合和自适应密度显示
- 重绘站点标识，增加线路与站点显示参数
- 在线更新改为保留旧数据的分区域更新
- 完整 GeoJSON 永久缓存，兼容旧版本区域缓存
- 从 Heap snapshot 恢复 17,564 个要素目录属性并随包固化
